프로젝트 코드 개발은 Microsoft Visual Studio 2022에서 이루어졌으며 
코드들을 src폴더에 넣고 bin에 .maz파일들을 넣고 f5를 누르시면 프로그램이 빌드및실행됩니다.
*2022에서 편집된 파일이라 2019에서 빌드되지 않는 경우 2022에서 실행했을 때 freeimage.dll이 없다고 빌드가 되지 않는 경우가 있습니다. 
이 경우엔 bin폴더에 fmod.dll, fmodL.dll, FreeImage.dll(2019에서 openframeworks를 실행했을 때 bin폴더 안에 생성됨)을 넣어주시면 빌드됩니다.
